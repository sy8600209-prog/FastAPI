# FastAPI Learning Journey

A beginner project where I learn how to build APIs with **FastAPI**, connect them to a **SQLite** database, and use a **Streamlit** frontend.

## What is FastAPI?

FastAPI is a modern Python framework for building APIs. It is fast, easy to learn, and widely used for serving machine learning models.

**Key features:**

- Very fast performance (built on Starlette and Pydantic)
- Automatic data validation using Pydantic
- Automatic interactive documentation at `/docs`
- Supports `async` and `await`
- Clean code with Python type hints
